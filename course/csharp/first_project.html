Creating Your First C# Project

In this section, we will create our first C# project using Visual Studio or Visual Studio Code. This will help you understand the basic structure of a C# application and how to run it.

Create a console project

Prerequisites

You should have Visual Studio 2022 or latest version of Visual Studio installed on your machine. If you haven't done so, please refer to the vs installation guide.

  • Open Visual Studio and select "Create a new project."

  • In the "Create a new project" dialog, search for "Console App". Select Console App that can run on .NET on Windows, Linux and macOS.

    If you are not using Visual Studio 2022 or later, you can select "Console App (.NET Core)" or Console App (.NET 5/6/7) or Console App (.NET Framework) and specify the .NET Core or .NET Framework version you want to use.

    Note

    If you don't see the Console App template, click on Install more tools and features link at the bottom of the dialog.

    This will open Visual Studio Installer where you can select the ".NET desktop development" workload to install the necessary templates.

  • Click "Next," then provide a name for your project (e.g., "Calculator"), choose a location to save it, select "Create a new solution" on Solution dropdown and provide a solution name."

  • Click "Next".
  • In the Additional information window, Select latest available .NET version from the dropdown.
    • Don't check Enable container support
    • Don't check do not use top-level statements
    • Don't check Enable native AOT publish

  • Click "Create" to create the project.

Run the app

  • Click a play icon with a Calculator label on it in the left.

Create a console project

Prerequisites
  1. The latest .NET SDK

  2. You should have Visual Studio Code installed on your machine. If you haven't done so, please refer to the VS Code installation guide.

  • Open Visual Studio Code.
  • Open the terminal in VS Code (View > Terminal or Ctrl + `).

  • Create a new directory for your project and navigate into it: 
    
mkdir Calculator # Create a new directory named Calculator
cd Calculator # Navigate into the Calculator directory
dotnet new sln # Create a new solution file
dotnet new console -n Calculator # Create a new console application named Calculator
dotnet sln add Calculator/Calculator.csproj # Add the Calculator project to the solution
  • Open the project in VS Code: 
    
code . --reuse-window
  • In the Do you trust the authors of the files in this folder? dialog, select Yes, I trust the authors

Run the app

To run app, run the command 


dotnet run --project Calculator
OR
  • Click Run menu on the top
  • Click Run Without Debugging or press Ctrl + F5

    If asked to select a debugger, select C#, then select C#:Calculator

  • You should see the output in the terminal.

You should see the output in the terminal. If you see any errors, make sure you have followed the steps correctly.

Congratulations! You have successfully created your first C# project and run it. In the next section, we will explore the different components of a C# project .
