Installing Visual Studio Code

Visual Studio Code (VS Code) is a free, open-source, and lightweight source code editor developed by Microsoft. It is available on Windows, macOS, and Linux and is designed to be fast, flexible, and highly customizable for developers. Unlike Visual Studio which is a dedicated IDE for .NET technology stack, VS Code is more like an extensible text editor. By installing extensions available in visual studio marketplace, VS Code features can be extended and used as a modern cross platform IDE.

  • Since, VS Code itself isn't an IDE like Visual Studio you will need to download latest version of .NET SDK and install it.

    Download Latest .NET SDK

    At this time don't install both x64 and x86 variant of same verion of .NET SDK. This will conflict the dotnet version and will have to manually resolve the issue.
  • Download VS Code for your operating system and install it.

    Download Latest VS Code for windows

  • Restart your computer to finish installation if required.
  • Open terminal and verify dotnet is installed and is available to use 
    
$ dotnet --version

    You should see .net version if it is properly installed & available. If you don't see anything follow this instruction and add donet installation path in environment variable. Recheck in terminal now if dotnet is resolved or not.

  • Open VS Code and complete necessary welcome setups
  • On left side of VS Code click Extensions and search for C#
  • Install C# and C# Dev Kit extensions
